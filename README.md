### 🚀 Projetos de Alto Impacto

#### 🏭 **Factory ERP (Gestão Industrial Inteligente)**
Sistema completo de Planejamento de Recursos Empresariais (ERP) com arquitetura Cloud-Native e foco em otimização de estoque.
- **Backend:** Java 17, Quarkus, Hibernate Panache, MySQL 8.
- **Frontend:** React, Vite.
- **Destaque:** Implementação de um algoritmo matemático para analisar a engenharia de produtos (Bill of Materials) e sugerir produções lucrativas. Testes E2E com Cypress.
[🌍 Acessar Sistema em Produção](https://app.lmtools.com.br/)

#### 📦 **GestorFlex / Pratto**
Ecossistema comercial completo com PDV, gestão de mesas e um módulo de delivery integrado.
- **Backend:** Java 17, Spring Boot, Spring Data JPA.
- **Frontend:** React + Tailwind CSS.
- **Destaque:** Sincronização em tempo real entre pedido web e painel do restaurante com impressão térmica automática. Sistema operando em clientes reais.
[🐙 Acessar Repositório](https://github.com/maicuu/gestorfleex)

#### 📅 **Agendamento | Beleza Pura (BarberSaaS)**
Plataforma SaaS de agendamento multi-tenant com lógica complexa de disponibilidade.
- **Stack:** Node.js, MongoDB, Google Calendar API.
- **Destaque:** Sistema 100% em produção, atendendo clientes reais e automatizando a agenda de profissionais da área da beleza.
[🌍 Acessar Sistema em Produção](https://agendafacilbarber.com/belezapura) | [🐙 Acessar Repositório](https://github.com/maicuu/barber-saas-core)

#### 🏭 **Factory Optimization Engine**
Sistema de inteligência industrial para maximizar lucros através de otimização algorítmica de inventário.
- **Backend:** Java 17, Quarkus, Hibernate Panache, PostgreSQL (Neon Cloud).
- **Frontend:** Vue 3 (Composition API), Vite, Tailwind CSS, i18n.
- **Destaque:** Implementação de lógica de precisão absoluta com `BigDecimal` para gestão de recursos e lucro. Sistema multilíngue com cobertura total de testes automatizados (JUnit/Vitest) e CI/CD via GitHub Actions.
[🐙 Acessar Repositório](https://github.com/maicuu/factory-optimization-challenge)

#### 🎮 **LoL Performance Analyzer**
Ferramenta de Data Analytics que consome a Riot Games API para extrair métricas de E-sports.
- **Stack:** Python, Requests, collections.Counter.
- **Destaque:** Cálculo matemático de KDA, Farm/minuto e otimização de mineração de arquivos JSON massivos.
[🐙 Acessar Repositório](https://github.com/maicuu/lol-performance-analyzer)

#### 🤖 **Automação CRM & Leads**
Fluxo inteligente que reduziu o tempo de resposta de leads de 2 horas para 5 segundos.
- **Stack:** n8n, JavaScript, Webhooks.
